# Let It Fly ✈️

A cinematic 3D paper-plane flight experience built with Three.js and Vite.

Features a fantasy-world intro video, typewriter animations, scroll-driven CatmullRomCurve3 flight paths, particle dissolve effects, and a whimsical post-landing sequence with cake, balloons, and character models.

## Tech Stack

- **Three.js** — 3D rendering
- **Vite** — Build tool
- **GSAP** — Animation library
- **GitHub + Vercel** — Deployment

## Development

```bash
npm install
npx vite
```

## Deployment

Push to GitHub → Vercel auto-deploys from `master` branch.
